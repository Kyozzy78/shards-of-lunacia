# Decision record

## D-007 — September 20 user-requested rebuild (supersedes D-002/003/004 defaults)

The rejected slab/cube scene is replaced with a continuous planted island and imported CC0 Kenney Nature/Castle scenery. Logical movement stays grid-based. Default player identity is the exact named GLB, not unrelated fixture genes labelled Kibo. Mixer remains an explicit `?mixer` guest path.

The earlier claim that Origins was private/unavailable was incorrect: its public recursive tree and LICENSE.md were inspected and pinned. Actual Chimera resources there are 2D/Spine, not 3D GLBs. Official portrait markers are a disclosed interim; the requested 3D files remain missing. No Spine runtime is introduced without a separate license.

User-supplied MP3s are integrated for local play; public music redistribution permission is not established. See ASSET_MANIFEST.md and RESOURCE_AUDIT.md. The earlier broad release-ready assertion is withdrawn; RELEASE_REPORT.md lists remaining gaps.

## D-001 — deterministic grid authority

Use a 14×10 integer grid with reproducible path, LOS, cover, visibility, and damage rules. Visual elevation never changes legality. This protects gameplay clarity and tests.

## D-002 — official character boundary

Pin Mixer 3D at `812f0ee…`; actively attempt it for Kibo with local fixture genes; use official self-contained GLBs for Bing/Xia and as the documented Kibo safety net. This keeps the game playable when the alpha content is absent, slow, or fails strict assembly. The adapter logs the precise Mixer exception. The installed system Node was 20.11.1, so a workspace-local Node 22.17.1 was used for compatibility work.

## D-003 — rights-first assets

Do not import the private Origins kit without locally inspectable permission. Use original procedural Chimeras/VFX. Do not ship YouTube music. Provide a silent music channel and volume preference until approved audio is present.

## D-004 — original environment plus optional Kenney path

Ship original code-native ruins so no download is required. Add the requested Kenney catalog link; Kenney states asset-page downloads are CC0. Castle Kit is the recommended optional replacement source, subject to recording exact downloaded version/files before import.

## D-005 — no UI framework

Six units and three screens do not justify React or a state library. Typed templates and delegated bindings keep the bundle small and maintain simulation/presentation separation.

## D-006 — integrity receipt line endings

The official validator recomputed all 5,821 entries, `521,569,032` bytes, manifest SHA-256 `cf9274…bfbd`, and aggregate SHA-256 `683aa4…0672`, then failed its final raw-string comparison because Windows Git checked out `content-integrity.json` with CRLF while the generator emits LF. The official receipt was not rewritten. This is a reproducible tooling blocker, not an asset hash mismatch; the copied content remains sealed and the GLB safety path keeps gameplay runnable.
